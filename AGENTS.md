# AGENTS.md

## Project Summary
- Personal portfolio site for Samiul Kabir.
- Built with Next.js (pages router), React 18, MUI, Tailwind CSS, and AOS.

## Key Paths
- pages/index.js: Home page composition.
- components/: UI sections and cards.
- data/: content arrays (skills, projects, experience).
- public/assets/: resume PDF.
- public/images/: logos and project images.
- styles/: global and component CSS.

## Dev Commands
- npm install
- npm run dev
- npm run build
- npm run start
- npm run lint

## Notes For Changes
- Uses Tailwind utility classes alongside MUI components.
- External links should use target _blank with rel noreferrer.
- Font loading uses next/font/google.
- AOS animations are initialized in several components.
